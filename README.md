College Management System

A web-based College Management System developed using Python and Django. This project helps manage students, faculty, departments, courses, attendance, fees, library, and notices through role-based authentication. It provides a simple, responsive, and user-friendly interface for college administration.

Features

- Role-Based Login System
- Principal Dashboard
- HOD Dashboard
- Faculty Dashboard
- Student Dashboard
- Student Management
- Faculty Management
- Department Management
- Course Management
- Attendance Management
- Fee Management
- Library Management
- Notice Board
- Responsive UI
- Secure Authentication

- Django

- JavaScript
- SQLite

Installation

Clone the repository

git clone https://github.com/prathamesh302008-ux/College-Management-System.git

Go to the project folder

cd College-Management-System

Create Virtual Environment

python -m venv venv

Activate Virtual Environment

Windows

venv\Scripts\activate

Install Required Packages

pip install -r requirements.txt

Apply Migrations

python manage.py makemigrations

python manage.py migrate

Run Server

python manage.py runserver

Open your browser

http://127.0.0.1:8000/
